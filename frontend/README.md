# CONCIERTOS FINDER
https://conciertofinder.pages.dev/
Conciertos finder es una pagina que te permite encontrar los conciertos proximos a suceder cercanos a tu ubicacion, dandote informacion actualizada de donde encontrarlos, comprar entradas y como llegar

*El proyecto se divide en este repositorio que es el front de la pagina en rect y una api desarrollada en django que permite obtener la informacion de la app en json
